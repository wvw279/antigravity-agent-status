# Agent Status v1.6.1

### How to install or update
1. Download **`Antigravity-Agent-Status-Installer.zip`** below.
2. Extract the archive to any folder.
3. Run **`INSTALL.bat`** and click **Install / Update** — the installer will automatically update the plugin and relaunch Antigravity (all your custom presets and settings are preserved).

## v1.6.x — Адаптивная локализация (Auto / EN / RU)
- **v1.6.1:** Добавлена защита английской локализации панели от перехвата внешними русификаторами (`Compact` больше не подменяется на «Сжать контекст», `Auto` — на «Авто», `Thinking…` — на «Размышление…»), а также перевод живого статуса «Размышление…» в компактном и полном режимах.
- **v1.6.0:** Добавлена адаптивная локализация панели под язык интерфейса Antigravity: автоопределение языка по UI приложения (с подстройкой на лету), переключатель `Auto / EN / RU` в настройках (`⚙`) с сохранением на диск в `prefs.json`, а также перевод всех элементов панели, названий встроенных пресетов и живых статусов работы агента (`Reading… / Читаю…`, `Thinking… / Думаю…`, `Ready / Готов к работе`).
